# 🌤️ MeteoBot — Telegram-бот для метеорологии и умных советов

Персональный метеорологический ассистент с привязкой к региону, почасовым анализом осадков («брать ли зонт»), рекомендациями по слоям одежды и ежедневными утренними брифингами.

---

## 🚀 Быстрый старт

### 1. Настройка токена
Откройте файл `.env` в корне проекта и укажите ваш токен от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
DEFAULT_TIMEZONE=Europe/Moscow
```

### 2. Запуск в режиме разработки (с автоперезагрузкой)
```bash
cd /home/belli/meteobot
npm run dev
```

### 3. Сборка и запуск в production
```bash
npm run build
npm start
```

## 🌟 Ключевые возможности

### 📍 Обязательный онбординг с привязкой к региону
* При первом старте (`/start`) бот сразу запрашивает локацию пользователя:
  * Кнопкой **«📍 Отправить мою геопозицию»**
  * Или выбором из популярных городов
  * Или текстовым вводом любого города мира
* Все последующие расчеты (зонт, температура, графики) рассчитываются строго под сохраненный регион.

### ☂️ Глубокий анализ осадков («Брать ли зонт?»)
Бот анализирует не просто факт дождя прямо сейчас, а:
* Почасовую вероятность осадков на ближайшие 12 часов;
* Объем осадков (морось, умеренный дождь, затяжной ливень, мокрый снег);
* Точное время начала: *«Захватите зонт! Около 15:00 ожидается дождь (вероятность 75%)»*;
* Наглядную шкалу вероятности осадков по часам прямо в сообщении.

### 👗 Гардеробный совет («Что надеть?»)
* Рассчитывается по температуре **«Ощущается как»** (с учетом порывов ветра и влажности);
* Подсказывает, когда нужна ветровка, а когда — термобелье или шарф.

### 🔔 Ежедневные утренние брифинги
* Автоматическая рассылка утренней сводки в удобное время (по умолчанию `07:30`, можно изменить в `/settings`);
* Экстренные предупреждения о штормовом ветре (порывы от 15 м/с) и резких ливнях.

## 📁 Архитектура проекта

```text
meteobot/
├── data/                    # База данных SQLite (пользователи, локации, настройки)
│   └── meteobot.sqlite
├── src/
```

## 🛠️ Запуск как фоновой службы systemd (24/7)

Создайте файл службы:
```bash
sudo nano /etc/systemd/system/meteobot.service
```

Вставьте конфигурацию:
```ini
[Unit]
Description=MeteoBot Telegram Service
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=belli
WorkingDirectory=/home/belli/meteobot
ExecStart=/usr/bin/npm run dev
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Активируйте и запустите:
```bash
sudo systemctl daemon-reload
sudo systemctl enable meteobot
sudo systemctl start meteobot
```
